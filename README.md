# Template Two

A landing page template built from a design, to practice HTML and CSS layout.

**Live demo:** https://moh9180812-cyber.github.io/Html_And_Css_Template_Two/

## Features
- Hero and content sections
- Custom Work Sans font
- normalize.css and Font Awesome

## Built with
HTML, CSS, Font Awesome

## Run locally
```bash
git clone https://github.com/moh9180812-cyber/Html_And_Css_Template_Two.git
cd Html_And_Css_Template_Two
```
Open `index.html` in your browser. No build step or install needed.
